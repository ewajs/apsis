# 0007. Installable PWA

- Status: Accepted; implemented in step 0.3, live-data caching in 1.4 (archive in M3),
  textures precached from 2.1, the sky from 2.3b (the precache is about 5.3 MB in all);
  spacecraft models cached once seen, never precached (5.6, ADR 0013).
- Date: 2026-11-22

## Decision

Apsis is a PWA built with `vite-plugin-pwa` (as Grama is): installable, works
offline, and updates itself.

- **App shell** (code, styles, fonts, textures): precached. A new version only when
  the code changes; it installs in the background and applies on the next launch
  (`autoUpdate`). There is no user state worth interrupting for.
- **Data is not precached.** It is cached at runtime, by kind:
  - live chunks and the catalogue: _stale-while-revalidate_ (show the cached copy at
    once, refresh in the background);
  - archived chunks (`data/archive/…`): _cache-first_ (they never change), since 3.3.
- The page always shows how fresh the data is ("data as of …").

## Reasons and alternatives

- **Why data stays out of the precache.** The precache manifest is the app's version.
  The site redeploys daily with new data (ADR 0008); precaching the data would make
  every visitor download an "update" every day.
- **Textures precached.** The 2k set is about 5 MB. Acceptable for a 3D app, and the
  scene is useless without them. Revisit if first load on a phone is slow; they can
  move to cache-first at runtime.
